# Java Fundamentals and Setup

## Project Overview

This project is created as part of the Java Developer Fresher internship to understand the fundamentals of Java development and configure the development environment.

## Objective

The objective of this project is to:

- Set up the Java Development Kit (JDK).
- Verify Java and Java Compiler installation.
- Create and run a basic Java application.
- Understand Java project structure.
- Practice using VS Code as a Java development environment.
- Set up Git for version control.
- Upload the project to GitHub.
- Verify the complete development workflow using a Hello World application.

## Technologies and Tools Used

- Java JDK 26.0.2
- Java Compiler (javac)
- Visual Studio Code
- Git
- GitHub
- Windows PowerShell

## Java Program

The project contains a simple Java program that verifies whether the Java development environment is working correctly.

The program displays:

```text
Hello World!
Java Fundamentals Setup
Java Developer Fresher Project
Environment setup completed successfully.
```

## Setup Verification

The Java installation was verified using:

```bash
java -version
```

and:

```bash
javac -version
```

The installed Java version is JDK 26.0.2.

## Running the Project

Compile the Java program using:

```bash
javac src\Main.java
```

Run the program using:

```bash
java -cp src Main
```
